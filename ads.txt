# pages, so it lives here (https://badgames4eva.com/ads.txt) rather than in a game repo.

# NOTE ON SUBDOMAINS: crawlers resolve ads.txt against the page's own host, so a game on

# its web build; today the web builds serve no ads (CONFIG.vastTags is null), so there is
# nothing to declare and no delegation line.
